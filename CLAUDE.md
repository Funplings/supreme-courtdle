# CLAUDE.md

## Project

supreme-courtdle — a daily Supreme Court case quiz. Vite + vanilla TypeScript + Tailwind CSS. No framework. Case data from the Oyez API via a Python scraper.

## Commands

```bash
npm run dev        # dev server (localhost:5173)
npm run build      # production build → dist/
python oyez_scraper.py   # re-scrape cases.json and download justice images
```

## Key files

- `src/main.ts` — all rendering and event handling; edit this for UI changes
- `src/game.ts` — daily case selection logic
- `src/types.ts` — TypeScript interfaces
- `public/cases.json` — scraped case data; regenerated by scraper
- `public/schedule.json` — hand-maintained date → docket key map
- `public/justices.json` — hand-maintained justice biographical data
- `oyez_ids.csv` — list of cases to scrape

## Conventions

- Tooltips use pure CSS hover (`.term-tip::after`, `.justice-wrap/.justice-tooltip`), not Tailwind `group-hover` — the latter is unreliable inside `innerHTML`.
- Legal terms are highlighted automatically in all prose fields via `highlightTerms()` in `main.ts`. Add new terms to the `LEGAL_TERMS` map there.
- Justice name matching uses a last-name + suffix index (`nameKey()` / `buildJusticeIndex()`) to handle abbreviated API names vs. full names in `justices.json`.
- If the scraper logs `winner: None` for a case, add a manual override to `WINNER_OVERRIDES` in `oyez_scraper.py`.
- Game state is stored in localStorage under the key `supreme_courtdle_daily`. Reset it in the browser console with `localStorage.removeItem('supreme_courtdle_daily')`.
- Colors: navy `#1B2A4A`, gold `#C9A84C` (defined in `tailwind.config.js`).
- Max content width: `max-w-3xl`.
