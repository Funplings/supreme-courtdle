# supreme-courtdle

A daily Supreme Court case quiz. One landmark case per day — read the facts, identify who prevailed.

Built by [Funplings](https://funplings.github.io/). Case data sourced from [Oyez](https://www.oyez.org).

## Playing

Visit the site. Read the background and the legal question, then guess which party won. Results reveal the vote breakdown with justice photos.

One case per day. Come back tomorrow for a new one.
